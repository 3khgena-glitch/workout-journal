# Журнал тренувань — PWA

PWA для iPhone через GitHub Pages.

## Функції
- тижневий план без окремої вкладки «Історія»;
- готові шаблони тренувань і вправи з наданого списку;
- параметри повторів і ваги/еспандера для конкретної тренування;
- секундомір розминки, основної частини та заминки;
- таймер відпочинку;
- інтервальний таймер;
- окремий попереджувальний сигнал за 5 секунд до завершення обратного відліку;
- окремий сигнал завершення та сигнал переходу між циклами;
- збереження даних у localStorage;
- міграція старих даних `workoutJournal.v1`;
- Service Worker з оновленою версією кешу.

## GitHub Pages
Завантажте файли у корінь репозиторію та увімкніть GitHub Pages для гілки `main` і папки `/ (root)`.

## iPhone
Відкрийте адресу GitHub Pages у Safari → Поділитися → «На екран Домой».

## Обмеження
Safari/PWA може обмежувати відтворення звуку, коли сторінка повністю неактивна або екран заблокований. Таймери рахують час за системними timestamp, а не за кількістю виконаних `setInterval`/`setTimeout`.
