# Журнал тренировок

PWA для GitHub Pages и Safari/iPhone. Сервер не требуется.

## Файлы

Замените в репозитории `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `sw.js`. Папку `icons` оставьте существующую.

## GitHub Pages

Settings → Pages → Deploy from branch → `main` → `/root` → Save.

После публикации откройте адрес GitHub Pages в Safari на iPhone → Поделиться → «На экран Домой».

## Основные функции

- текущая неделя и план тренировок;
- создание/редактирование/удаление тренировок;
- справочник упражнений;
- повторы и текстовое поле веса/эспандера для конкретной тренировки;
- секундомеры разминки, основной части и заминки;
- обратный таймер отдыха;
- интервальный таймер;
- предупреждающий звук за 5 секунд до конца обратного отсчёта;
- отдельные звуки окончания периода и перехода цикла;
- звук Вкл/Выкл;
- пресеты интервалов;
- сохранение выполненной тренировки прямо в плане через «Деталі»;
- локальное хранение данных;
- timestamp-расчёт таймеров при возврате из фона;
- обновление Service Worker через новую версию кэша.

## Ограничения iPhone/PWA

Safari может ограничивать воспроизведение звука, особенно когда приложение полностью закрыто или экран заблокирован. Приложение не имитирует гарантированную работу звука в таких условиях.
