# Журнал тренувань

PWA для iPhone через Safari та GitHub Pages.

## Структура
- **Тиждень** — окремий календарний екран.
- **Тренування** — окремий список готових комплексів.
- **Вправи** — довідник вправ.
- **Таймери** — секундомір, відпочинок та інтервали.

У тренуванні кожна вправа може мати кілька окремих підходів. Один і той самий рух можна додати кілька разів із різною вагою/видом еспандера та кількістю повторів.

## Оновлення
Після заміни файлів у GitHub Pages Service Worker використовує нову версію кешу.

На iPhone: Safari → Поділитися → На екран «Домой».
