# Журнал тренировок — PWA

Локальное PWA для iPhone без Mac, Xcode, сервера хранения данных, регистрации и платных сервисов.

## Возможности

- текущая неделя и переход между неделями;
- создание, изменение, удаление тренировок;
- назначение тренировки на день недели;
- выбор и порядок упражнений;
- редактируемый справочник упражнений и поиск;
- отметка выполнения с автоматической датой/временем;
- примечания к выполнению;
- история с подробностями;
- локальное хранение в `localStorage`;
- manifest + service worker;
- установка на экран «Домой» через Safari при HTTPS.

## Запуск на Windows

Для локальной проверки можно использовать Python 3:

```powershell
py -m http.server 8000
```

Откройте `http://localhost:8000`.

Для установки на iPhone нужен HTTPS-хостинг. Самый простой бесплатный вариант — GitHub Pages:

1. Создайте репозиторий на GitHub.
2. Загрузите все файлы проекта, сохранив структуру папок.
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Выберите `main` и `/root`.
6. Откройте выданный HTTPS-адрес в Safari на iPhone.
7. Поделиться → На экран Домой.

Данные приложения хранятся локально в браузере конкретного устройства. Они не синхронизируются между iPhone и Windows PC.

## Важно

Не удаляйте данные сайта в Safari, если хотите сохранить журнал. Очистка данных сайта/браузера может удалить локальный журнал.

Обновление кода не должно менять ключ `workoutJournal.v1`, иначе потребуется отдельная миграция данных.
